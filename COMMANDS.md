# Angular Commands

## Development

Run Application

```bash
ng serve
```

Build Application

```bash
ng build -c development
```

---

## QA

Run Application

```bash
ng serve -c qa
```

Build Application

```bash
ng build -c qa
```

---

## Production

Run Application

```bash
ng serve -c production
```

Build Application

```bash
ng build -c production
```
